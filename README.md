# Product List with Cart - Pure CSS & Vanilla JavaScript

A fully functional e-commerce shopping cart interface built with pure vanilla HTML, CSS, and JavaScript. This project is a solution to the [Frontend Mentor Product List with Cart challenge](https://www.frontendmentor.io/challenges/product-list-with-cart-5MmqLVAp_d).

## 🚀 Live Demo

**[View Live Site](https://franz-james-kaba.github.io/product-list-with-cart-pure-css/)**

## 📋 Project Overview

This is a fully responsive dessert shop interface featuring:
- ✅ Interactive shopping cart with real-time updates
- ✅ Add, remove, and adjust item quantities
- ✅ LocalStorage persistence (cart survives page reloads)
- ✅ Order confirmation modal
- ✅ Fully responsive design (mobile to desktop)
- ✅ Accessible markup with ARIA labels

## 🛠️ Built With

- **HTML5** - Semantic markup
- **CSS3** - Grid, Flexbox, Custom Properties
- **Vanilla JavaScript (ES6+)** - No frameworks
- **LocalStorage API** - Cart persistence
- **GitHub Pages** - Deployment

## 🎯 Features

### Shopping Cart Functionality
- Add items to cart with single click
- Increment/decrement quantity controls
- Remove items from cart
- Real-time total calculation
- Empty cart state with illustration

### User Experience
- Smooth transitions and hover states
- Visual feedback when items are in cart
- Keyboard accessibility (ESC to close modal)
- Order confirmation with summary

### Responsive Design
- **Mobile** (<480px): 1-column product grid
- **Large Mobile** (≥480px): 2-column grid
- **Tablet** (≥768px): 2-column grid + sticky cart sidebar
- **Desktop** (≥1024px): 3-column grid + sticky cart sidebar

This project follows the design specifications from [Frontend Mentor](https://www.frontendmentor.io), including:

## 🌟 Key Highlights

- **Zero Dependencies** - No npm packages, no build process
- **Pure Vanilla JS** - No frameworks (React, Vue, etc.)
- **Modern CSS** - Grid, Flexbox, Custom Properties
- **Accessible** - ARIA labels, semantic HTML, keyboard support
- **Persistent State** - Cart data saved to LocalStorage
